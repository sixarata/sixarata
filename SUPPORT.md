# Getting Support

## Questions and design discussion

Use [GitHub Discussions](https://github.com/sixarata/sixarata/discussions) for setup help, engine questions, room-design conversation, and open-ended ideas. Include your browser, operating system, input device, and Sixarata revision when they matter.

## Reproducible bugs

Use [GitHub Issues](https://github.com/sixarata/sixarata/issues) for reproducible bugs and focused improvements. Search first, choose the closest issue form, and include a minimal reproduction.

Sixarata is maintained as an open-source project. Response times are best effort, and public project spaces are not emergency or private support channels.

## Security

Do not post vulnerabilities or credentials publicly. Follow [SECURITY.md](SECURITY.md) for the currently available private-reporting path.
